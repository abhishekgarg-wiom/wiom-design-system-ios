Term mappings for customer-app copy. Any section marked not in use is a retained vocabulary inventory, not a customer-screen requirement. When writing UI text, ALWAYS use the Hindi term from this glossary. Do not invent new translations.

## Usage Rules

1. **Keep English for acronyms:** OTP, GST, ISP, WiFi, WhatsApp, ID : these are universally understood
4. **Status** can be "स्थिति" (formal) or "स्टेटस" (casual) : prefer "स्टेटस" in app UI for casual tone
5. **Only** can be "मात्र" (formal/emphasis) or "सिर्फ" (casual) : prefer "सिर्फ" in chat, "मात्र" in pricing
6. ⟨iOS⟩ When a term is missing or a spelling is unclear, don't invent one: ask the design team, which adds it here. Use the spelling already in the app's string catalog when it exists.
7. **Customer recharge terminology:** use रिचार्ज on every customer-read surface, including receipts. Do not rename code identifiers or schema keys based on copy terminology.

Partner-only vocabulary and original Usage Rules 2 and 3 are preserved in [glossary-partner-not-in-use.md](glossary-partner-not-in-use.md). That file is not in use for iOS customer screens or copy.
